# The poem about permission

A short poem about agency — the power to ask and to be given. It follows a speaker who stands all morning at a gate with a request folded small, afraid to unfold it, until one plain question turns the lock from the other side: the gatekeeper steps aside, and the asking itself turns out to have been the key all along. Written for the make.fun bounty of the same name.

## How to run

Requires Node 22 or later. The program writes the poem to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default):

```sh
node main.ts
```
